### 5.1 FuseBox **#747** — kind 0x31, the only parameterised one [D; M FuseBox_Create 0x1b0448 / FuseBox_Update 0x1adfe8 / FuseBox_Register 0x1b0970]

`OBJECT_FuseBox` @(28.00, 40.00, −18.15), params **[p0 = script 0x0600004B, p1 = 57, p2 = 55, p3 = 103, p4 = 55]**
(the older doc rows and alarm-panel-06's "script 0x0600006B" mis-read the hash; the disc says 0x0600004B —
census probe). The other four 0x31s (#349/#350/#366/#367, destroyed props) have no params → not fuseboxes
([M] the create only builds one from a 0x31 with a script hash in p0; the port matches).

- `FuseBox_Create`: params 1–4 → ext +0x54/+0x56/+0x5C/+0x5E (two channel words per wire group: group 0 =
  p1/p3, group 1 = p2/p4), class 0x3C, `SP_Create(script p0, mode 0x40 preloaded, FuseBox_Register callback)` —
  the box's script runs at LOAD, so the wires exist from frame 1 [M 0x1b0448].
- `FuseBox_Register`: the script's event-0xF hand-off files each wire entity into the box's two 10-slot groups
  and counts them [M 0x1b0970].
- `FuseBox_Update`: each frame every registered wire's hit list is filtered (`Collide_FilterBullets(list,
  0xfffd)` [M 0x1adfe8:~88]) — a wire whose surviving contact list is non-empty DIES (`Control_NextLOD` +
  `Effect_RemoveSObjs`; the visual goes away) [M :93-96]. The filter keeps only category words 0x0000/0x0002
  ([L weapon_data]: guns 0x0008 filtered, the Laser 0x0002 cuts, grenades 0x0000 cut, the watch/Decryptor
  beams 0x0100 filtered) [M Collide_FilterBullets 0x1ece30].
- A group-1 wire death hurts Bond 5.0 **iff +0x56 == 0** — here +0x56 = p2 = 55 ≠ 0, so cutting the alarm
  bundle never hurts [M :99-101]; the death also zeroes group 0's second word +0x5C [M :102].
- A group emptied with a non-zero registered count writes both its channel words (one-shot, zeroed after):
  **group 0 → ch 57 (the searchlights off) + ch 103; group 1 → ch 55 (the alarm) + ch 55** [M :110-123; D params].
  Channel consumers: #703 (ch 57 → sound 241, the lights-off clunk), #712 (ch 103 → sound 331), the searchlight
  gate (ch 57 held off = the heads stop), #702 the siren (ch 55).
- Port: ✓ `fusebox.rs` (ported for 07000014 with unit tests; event-0xF registration wired in nis.rs/drone.rs).
  **06 live test added this task** (`fusebox_06_live`): laser-cut group 0 → ch 57 + 103; group 1 → ch 55; the
  sister holds the fire and asserts no channel.
