# 0700000b — Tower C (executive floor + the roof, `UpdateMFX_03TowerC` 0x113a20)

The Tower mission's last level: from the outer balcony Bond works up to the executive floor,
plants the Q-Worm on Mayhew's computer, retrieves the NightFire files from the secure terminal,
escapes to the roof, takes the parachute from the helicopter and jumps. 51 maps, 242 objects, 380
placements, 10 drones, 177 collision cels [D level-survey].

## Not ported / gaps (with the game function)

- **PCQWorm** — useobj.rs (as 0a).
- **The keycard lock switch** — useobj.rs's Switch (E-toggle ch 9) [M 0x1b02a8]; its animation
  script (0x0600066D) is presentation (the channel write the script makes is reproduced by the
  toggle).
- **The writers of ch 0x54 / ch 0x06 / ch 0x59 / ch 0x57** — not found in the level's trigger,
  archive-script or switch dumps [D; the pack scripts 0780000b/0790000b were dumped raw and their
  stream bytes hold no readable Event-0xD writes in the first 24 commands]. These gate obj9's
  OR(ch 8, ch 6) and obj10's ch 0x59 — the walkthrough drives them where the dumps end, and the
  doc flags them as the level's open questions (candidates: the lift-ride script's events and the
  secure-terminal SP chain, whose 0x06000035/0x06000037 scripts write ch 10/11 — a further
  relay).
- **The lift ride** (lift_scriptplayer mode 8 + stop trigger): the port's ScriptPlayers do not
  carry Bond; the walkthrough teleports between floors (the task allows teleport-walking).
- **Swimming / the dome water**, **Monitor**, **GT turrets** — presentation.
